# FX11 仪表 v50：图标缩放与视觉校正

## 设置与兼容

「高级 → FX11 仪表 → 上下模块图标大小」提供默认 1×、1.1×、1.2×、1.3×、1.4×、1.5×。

只缩放灯光、辅助驾驶、跟车距离、续航、AutoHold、驻车图标。时间、温度、剩余续航数字、ACC 设定速度和档位文字不缩放；上下背景条、圆盘大小、地图窗口也不跟着缩放。旧版 2× 设置自动按 1.5× 图标显示。保留已有样式、日夜选择、按键配置和 CarPlay 配置。

跟车汽车矢量图的绘制区域是 48×48，上一版归一化时按 36×36 处理，导致偏大。本版按实际 48×48 区域缩放，两处汽车图标（ACC 和跟车距离）一起修正。

底部布局固定为：时间 | 温度 | 剩余续航 | AutoHold | 手刹 | 档位。为图标放大留出固定空间，新增续航与 AutoHold、AutoHold 与手刹、手刹与档位之间的竖线。AutoHold 和手刹继续默认灰色、实际保持为绿色、实际驻车为红色，数据源不变。

## 经典白天配色

外部底色为奶油色 #F7F0E2，中间内容底层、信息卡和上下模块采用白色；地图边缘的渐变蒙层改为白色。不会把 CarPlay 视频本身染成白色，也不会拿模拟地图替代实际地图。夜间配色保持原来的黑色。中央音乐歌名和歌手改用深色文字，进度条采用深绿色，保证在白底上清晰可见。

## 新仪表与设计图为什么有差异

v48 是从概念图手工绘制的基础 Canvas 版本，不是按设计稿完整还原。确实漏掉或简化了金属表圈、多层轮廓光、面板材质、星空的色彩层次，导航信息卡也直接沿用了经典仪表的宽条结构。不能把这些差异归因于屏幕设置。

另外，原设计图的三维城市地图和封面属于示意内容，运行时只展示真实 CarPlay 视频与当前曲目封面。没有接手机或没有封面时，实际画面会更空；地图建筑、路网和颜色由手机导航应用决定，仪表皮肤无法直接复刻设计图中的地图素材。

本版修复的视觉差异：

- 疾速赛道增加速度面板分层、细轮廓光与底部纹理，收窄音乐卡内容。
- 极夜双环增加金属外沿、内侧细刻度、当前数值的青色扇形及指示线。
- 曜石全景增加面板明暗层次、轮廓、音乐与转速分隔，并调整封面占比。
- 星空增加静态紫灰/靛蓝渐变、疏密和亮度不同的星点；白天使用浅灰紫暖色。
- 新仪表采用更紧凑的导航指令卡，剩余路程和时长放在中间下方；无导航时不展示这两块。
- 音乐仅在收到真实进度数据时展示进度条，不添加虚假的播放时间或仪表触屏按钮。

这仍是适配 1920×532 的原生绘制版本，不能宣称与概念图逐像素一致。交付截图来自当前绘制代码和明确的测试数据；截图中的数字、封面和导航文字不代表实车采集，测试图不会烘焙进 APK。

## 保留能力与检查

保留 V49 导航数据采集、普通 CarPlay、主屏镜像/缩放、原厂叠加、既有仪表及 FX11 车况读取。本版不改认证资源、不改车辆信号映射。

检查包括六档图标尺寸、旧设置迁移、放大后文字/圆盘/地图不变、车距图标边界、五条底部分隔线、白天奶油/白色配色、现有图标状态、九种设置语言、大字体设置截图，以及仓库完整测试、Lint 和构建。实车显示与真实地图叠加仍需要安装后验证。
