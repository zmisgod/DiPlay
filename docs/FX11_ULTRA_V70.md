## 本版修改

- 原版 Ultra 主题使用统一的主屏/副屏名称：displays.uuid、displayPanels.initialVideoStreams、插件、HID、viewArea、showUI、stopUI、缩放和关键帧请求一致。普通及仅空调模式保留原 UUID。
- 不再为主题额外承诺 LIVI 未协商的 uiContext；仍保留 UI Sync 和车辆协议。
- 首次 /info 中固定座位布局和 interiorStyle 带真实固定初始值，不再声明为未知。动态车辆值仍保持真实读取，缺失不伪造。
- 已协商车辆协议且事件连接就绪后，4 秒仍没有主屏 SETUP，向主屏 UUID 发送一次 showUI。它是针对捕获现象的恢复尝试，不能替代实车验证；不循环发送、不强迫切到普通模式、不关闭既有副屏。主屏已建立、会话关闭或手机请求原车 UI 时不发送。12 秒记录主屏 SETUP、首帧、副屏和事件连接状态。
- 记录协商功能、屏幕标识、资源归属、主屏恢复命令 CSeq 和手机响应状态；不记录认证密钥。
- 空调入口保存写入增加结果、修订号、时间和旧值核验；旧设置界面不得覆盖更新后的值，禁用该开关的 Android 视图状态回写。连接配置只读取一次入口选项，日志记录实际应用值；不自动打开/关闭入口、不代表车辆空调实际电源。

## 未改动

现有自定义仪表、方向盘、ESP32 固件/协议、普通 CarPlay 音视频和认证资产。原版 Ultra 的苹果本地 UI 合成与完整仪表数据仍未完成，选择该样式不等于已证明可以显示苹果原生表盘。
