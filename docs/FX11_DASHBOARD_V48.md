# FX11 仪表 v48

## 本次变化

在「高级 → FX11 仪表」中增加四种布局：疾速赛道、极夜双环、曜石全景、星空。除极夜双环固定夜间外，其他新布局可选择白天、夜间或按时间自动切换（06:00–18:00 白天），对应七套配色。保留 Midnight、全景、经典仪表、原厂叠加和普通 CarPlay。

新布局使用 Canvas 绘制，接入现有 FX11 车况、CarPlay 音乐、导航和地图数据。缺失车况显示未知，不使用演示数值；没有导航信息时不画导航文字卡片。白天的上下模块为亮色，所有完整仪表共用经典仪表的灯光、辅助驾驶、续航、AutoHold、驻车和档位图标。原厂叠加模式继续只负责叠加内容，不额外覆盖原厂状态栏。

「上下模块大小」提供默认、1.5 倍、2 倍。新布局和经典仪表在放大模块时调整仪表及中间内容位置。默认保持 1920×532 布局。

## 主屏 CarPlay 镜像

开启「仪表镜像主屏 CarPlay」后，仪表地图区域改用主屏视频流。镜像的是完整 CarPlay 画面，切换到其他应用也会显示该应用；不是 Android 本机地图，也不会改变主屏自身的尺寸。

- 默认 100% 等比完整显示；竖屏画面会留下侧边空白。
- 缩放 50%–400%，支持水平、垂直偏移及一键重置。
- 放大后超出地图窗口的边缘会被裁切，比例不被拉伸。
- 设置立即作用于仪表，无需断开手机。
- 关闭后恢复独立仪表地图流及其原有地图大小、位置设置。
- 音乐或胎压页面不会强制显示地图；镜像以所选布局的地图区域为准。

## CarPlay 连接后关闭蓝牙

高级设置复用上游的「CarPlay 期间暂停车机蓝牙」机制，可选延迟 5/10/15/30 秒，需要先完成车机本地 ADB 授权。设置在下次连接时生效。仅当蓝牙原本开启时才记录恢复状态；会话结束或下一次无线握手前恢复，不删除配对。

如果启用了「车机蓝牙音频」，控制器不会关闭蓝牙，以免切断声音。此版本需要在 FX11 实机验证系统是否允许该开关及无线连接能否稳定维持。

## 卡顿优化与证据

- 重复挂接同一个有效视频 Surface 时复用解码器，避免重新等待关键帧。
- 新增镜像目标仅配置新增目标，不向其他目标重复发送配置。
- 车况绘制与视频帧分离；地图收到首帧才更新显示状态，之后不随每个视频帧重画整个仪表。
- 背景绘制指令缓存；经典刻度缓存按可见精度更新，减少无意义的小数变化带来的重建。
- 诊断增加视频呈现帧数、最大帧间隔、超过 100ms 的间隔次数，并补充解码器呈现间隔，配合既有网络、解码、UI 绘制统计定位瓶颈。

镜像仍使用独立硬件解码目标，额外预览窗口仍会消耗资源。静止地图可能主动降低帧率，单个大帧间隔不等于故障。当前没有实车录制，不能认定此前卡顿的唯一原因或保证已完全消除。

## 本地验证与交付

运行仓库要求的单元测试、Android Lint 和 mobile/home/maphost 构建，并检查新布局的 1920×532 渲染截图、1/1.5/2 倍模块、紧凑/宽屏/阿拉伯语大字体设置截图。新增镜像比例、偏移、注册隔离、重复挂接不重启解码器等测试。

最终测试 APK 使用外部本地认证资源构建 standaloneDebug；认证资源不进入 Git。APK 的签名、版本、认证资源及原有 FX11 原生库需与此前版本核对。实车连接、真实地图、日夜切换、蓝牙恢复及流畅度仍需安装测试。
