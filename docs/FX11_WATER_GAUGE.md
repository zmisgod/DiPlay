# FX11 仪表水温百分比（v63）

用户已通过独立小工具确认原厂水温显示。沿用该探测实现：通过 `/system/bin/lssvc -v` 发现 QNX `192.168.118.2` 的 `GaugeModule` 当前 TCP 端口，只读订阅 event 5。数据是四个 little-endian int32：`[percent,level,extra,mode]`，已验证正常帧 `[50,4,0,1]`。

这是原厂水温表显示比例，不是摄氏温度。仅接受 percent 0..100、level 0..8、extra 0、mode 1；`[0,0,0,4]` 视为未知，不能解释为冷车。

所有仪表原先使用前舱温度的水温位置，统一读取独立 `COOLANT_GAUGE_PERCENT`，显示 `50%`；未知显示 `—%`。不会用前舱温度或旧摄氏度信号填补，也不会将百分比当摄氏度发送给 iPhone。原有气温、胎压温度与真正的摄氏度遥测不变。

`Fx11GaugeSource` 管理原生 `libfx11_gauge.so` 的生命周期、重连发现和订阅；断线、错误帧和超过 25 秒未收到有效通信时清空。ALIVE 只能延长仍有效的已读值，不能恢复过期值。服务最后一个观察者离开时销毁子进程。Android 11 普通 APK 只读路径，未增加 root 或车辆写入。

单元测试重放已确认的 50% 帧，并覆盖模式 4、非法范围、断线、过期、发现对端限制和禁止前舱回退。新 DiPlay APK 的实车读数仍需安装后核对；不将独立测试软件的成功等同于新包已实车验收。
