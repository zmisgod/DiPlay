# FX11 v52：封面背景与经典速度刻度

## 视觉与状态

经典仪表播放音乐且有可用封面时，整屏背景显示封面放大后的高斯模糊色块；两侧表盘、刻度扇形、边框和上下信息条采用同一封面的配色。以封面整体亮度、饱和度区分浅色和深色，数字文字保持对比度。实际灯光、AutoHold、驻车等状态颜色与车辆信号逻辑不变；AutoHold、手刹激活加粗保留。

暂停、缺少封面或清空曲目信息时回到已有日夜配色。白天基础背景从奶油色改为纯白；夜间及按时间切换仍保留。导航视频区域不被封面模糊层覆盖或染色；音乐、导航、胎压页共用两侧表盘配色。其他仪表和原厂叠加不使用此封面主题。

左侧经典速度盘仍为 0–240 km/h，每 20 km/h 一个数字；每段仅在 5、10、15 km/h 显示三个小圆点。移除速度盘内圈密集刻度，保留主刻线。右侧转速刻度与红区规则不变。

## 性能与兼容

封面变化时生成一次 64×64 缓存位图并做两遍可分离高斯卷积，提取主色；后续只绘制缓存。相同封面刷新车速不会再次模糊。表盘显示列表以数值、日夜和封面配色为键；换封面会正确失效，断开和回收的图片回到正常兜底。

未新增依赖、未改车况订阅、方向盘映射、认证资源、普通 CarPlay、镜像及地图数据来源。封面跟随真实 CarPlay 信息，不在 APK 中预置示例专辑图片。

## 验证

本地检查包括封面更换与原位更新、缓存复用、暂停/无封面/回收兜底、地图原始颜色、灯光与 AutoHold 语义颜色、转速红区、速度刻度点分布、白天颜色、既有仪表及全量仓库 CI。
