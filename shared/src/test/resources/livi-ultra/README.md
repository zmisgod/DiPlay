# LIVI interoperability fixtures

Generated by the unmodified bplist.rs, opack.rs and ui_sync.rs from
https://github.com/f-io/LIVI/tree/3f86ad72049aa52d2969f083812ea37c80b65ea6/native/crates/livi-cp/src
(GPL-3.0-or-later). These are synthetic reference payloads, NOT captures from a vehicle/iPhone.

01–07 reproduce the upstream UI Sync handshake test (version negotiation 3 → 2,
RESET, completion, allow-layout, request-layout and focus). DiPlay power-only mode
omits the layout request; the focus packet therefore uses sequence 4 rather than 5.
The example display/layout/palette IDs are test fixtures, not FX11 provisioning.

08–11 use the upstream OPACK encoder to encode pluginID=0 and nested pluginData:
configRequest(transactionID=1), registerRequest(2, values=[514]),
writeRequest(3, values={514: true}), writeRequest(4, values={514: false}).
These validate the raw OPACK carrier independently of DiPlay encoders.
All files exclude APTransport framing and stream encryption.
